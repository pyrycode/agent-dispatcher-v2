# #25 — `src/pipeline/sizing.ts` XS/S predicates + file-overlap

Second file under `src/pipeline/` (after #6). Lands three pure predicates the dispatcher's size gate and WIP=1 overlap rule will eventually compose against.

## Exports

- `XS_MAX_PRODUCTION_LINES = 30`, `S_MAX_PRODUCTION_LINES = 100` — policy thresholds from CLAUDE.md § "Sizing", named so a future edit must surface here and trip the boundary tests rather than silently drift the gate.
- `SizingDiff` — narrow input shape: `{ productionLines: number }`. Test exclusion happens at the caller (counted at the `src/git/` boundary, not here).
- `OpenPr` — narrow input shape: `{ touchedFiles: readonly string[] }`. Caller maps the GitHub PR-files payload to a string array before handing off.
- `isXS(diff)` — `true` iff `diff.productionLines < 30`. Strict less-than: 29 is XS, 30 is not.
- `isS(diff)` — `true` iff `diff.productionLines < 100`. Strict less-than: 99 is S, 100 is not.
- `fileOverlapsAny(touchedFiles, openPrs)` — set-intersection predicate. `true` iff at least one path in `touchedFiles` exact-matches some path in any `openPrs[i].touchedFiles`. Empty on either side → `false` (vacuous). Exact string equality, no path normalization, case-sensitive — caller canonicalises both sides at the I/O boundary.

`isS` is *not* "S but not XS"; an XS diff also satisfies `isS`. Predicates answer "fits within the ceiling?" — callers compose them inline (e.g. `isXS(d) ? "xs" : isS(d) ? "s" : "split"`) when they need a tier label.

## Test surface

`test/pipeline/sizing.test.ts`, vitest, RED-first. Boundary cases (29/30 for XS, 99/100 for S) are pinned one assertion per row so a regression points at the exact failing row. Two extra constant-pinning assertions backstop the boundaries: if a future change drifts both the constant and the boundary tests in lockstep, the constant assertion still anchors policy to its CLAUDE.md value.

`fileOverlapsAny` covers both empty-input cases, no-overlap, single-file overlap, second-PR / second-candidate-file overlap (exercises both inner-loop traversals), and a case-sensitivity guard (`"A.ts"` ≠ `"a.ts"`) that pins the no-normalization contract.
