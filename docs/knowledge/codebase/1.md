# #1 — CI workflow for scaffold toolchain

Adds `.github/workflows/ci.yml`. Single job on `ubuntu-latest` enforcing the four scaffold checks on every PR to `main` and every push to `main`:

1. `pnpm install --frozen-lockfile`
2. `pnpm typecheck` (`tsc --noEmit`)
3. `pnpm test` (`vitest run`)
4. `pnpm lint` (`biome check src test`)

## Configuration

- **Node:** `actions/setup-node@v4` with `node-version-file: 'package.json'` — reads `engines.node` (`>=22`), no new pin introduced.
- **pnpm:** `pnpm/action-setup@v4` with `version: 9` in workflow YAML. The repo has no `packageManager` field; the lockfile (`lockfileVersion: '9.0'`) is consumed by both pnpm 9 and 10. Workflow-local `version: 9` is the minimal pin.
- **Order:** pnpm/action-setup MUST run before setup-node. setup-node's `cache: 'pnpm'` resolves the store path by invoking the pnpm binary, so pnpm needs to be on `PATH` first. Reversed order yields "pnpm: command not found".
- **Concurrency:** `cancel-in-progress: true` on `ci-${{ github.workflow }}-${{ github.ref }}` — cancels superseded runs on rapid PR pushes.
- **Permissions:** `contents: read` only. No write scopes; later workflows that need them grant per-workflow.
