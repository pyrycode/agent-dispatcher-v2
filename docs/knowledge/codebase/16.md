# #16 — audit + adapt Go-specific references in ported agent CLAUDE.md

## What changed

Six agent docs in the sibling repo were de-Go-ified to read as TypeScript-native guidance:

- `po/CLAUDE.md` — 2 example-path edits
- `architect/CLAUDE.md` — ~7 edits incl. file-overlap example, "Files to read first" worked example, "Go Architecture Patterns" → "TypeScript Architecture Patterns" with rewritten bullets
- `architect/security-review.md` — ~7 edits flipping Go-stdlib crypto/TLS/subprocess primitives to Node analogues (`node:crypto`, `node:tls`, `child_process.spawn`, `argon2` npm / `crypto.scrypt`)
- `developer/CLAUDE.md` — ~10 edits incl. title, must-pass commands (`pnpm test` / `pnpm typecheck`), Biome non-negotiable, worked examples #128 and #155 generalized away from Go-stdlib specifics
- `code-review/CLAUDE.md` — ~10 edits incl. title, "TypeScript-Specific" subsection, `package.json` over `go.mod`, `pnpm` toolchain, `file.ts:42` example outputs
- `documentation/CLAUDE.md` — already clean; no edits

## What was deliberately kept

- All Pyrycode #N incident references (#29, #40, #41, #45, #55, #75, #128, #155, #182/#187, KitchenClaw #72/#73). These ARE the accumulated lessons per ticket AC #5 — including the `internal/sessions/pool_test.go` / `internal/update` paths embedded inside historical incident descriptions.
- Pyrycode branding (agent titles, `mcp__qmd__query(collection: "pyrycode-docs", …)`, `gh --repo pyrycode/pyrycode`, the `pyrycode/pyrycode/docs/protocol-mobile.md` reference in `architect/security-review.md`) — explicitly out of scope for this ticket; deferred to a follow-up that decides whether v2 needs its own QMD collection.
- The five lesson areas: sizing rules, anti-rationalization smell-phrase list, file-overlap branch-check, salvage flow (`#128` / `#155`), predicate-completeness. Wording shifted around the Go examples; the rules themselves are intact.
- Acceptable false-positive matches for `\bgo\b`: "go straight to commit", "go through", "go to Severity Levels", "go deeper, not shallower", "supposed to go through". Enumerated in the verification grep.

## Substitution table (canonical)

| Go reference | TypeScript replacement |
|---|---|
| `go test [-race] ./...` | `pnpm test` |
| `go vet ./...` / `go build` | `pnpm typecheck` |
| `gofmt` / `staticcheck` | Biome (`pnpm lint && pnpm format`) |
| `go.mod` | `package.json` |
| `cmd/pyry/main.go` | `src/dispatch-bin.ts` |
| `goroutines + context + errgroup` | `async functions + AbortSignal + Promise.all/allSettled` |
| `error` return convention | thrown `Error` (or typed subclass) |
| `crypto/rand`, `crypto/tls`, `argon2`, `crypto/subtle.ConstantTimeCompare` | `node:crypto.randomBytes`, `node:tls`, `argon2` npm / `crypto.scrypt`, `crypto.timingSafeEqual` |
| `file.go:42` | `file.ts:42` |
